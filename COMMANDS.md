# Commandes utiles

## Développement
| Commande | Description |
|---|---|
| `npm run dev` | Lance le serveur de développement local |
| `npm run build` | Compile TypeScript + build production (Vite) |
| `npm run preview` | Prévisualise le build production en local |

## Audit & Sécurité
| Commande | Description |
|---|---|
| `npm run audit:check` | Vérifie les vulnérabilités npm (bloque si moderate+) |
| `npm run audit:types` | Vérifie les erreurs TypeScript sans compiler |
| `npm run audit:all` | Les deux en séquence — à lancer avant chaque déploiement |
